# 白透亮调色方案

适用于用户明确指定“白透亮”的写真、婚纱、情侣和人像照片。先根据原片曝光、人物肤色、白衣细节和深色衣物调节；以下范围是起点，不是固定预设。

## 目标

- 中间调明亮、白色柔和、暗部轻盈但保留体积。
- 人物肤色明净暖润，背景相对偏冷且更干净。
- 黄绿青的环境脏感被整理；画面不发闷、不发灰、不数码艳。
- 婚纱、头纱和亮色物体仍有织物、刺绣或表面细节；黑衣和黑发仍有材质层次。

## 起始数据（Lightroom / ACR 逻辑）

| 参数 | 建议范围 | 默认起点 |
| --- | ---: | ---: |
| 曝光 | +0.45 ～ +1.20 | +0.75 |
| 对比度 | -15 ～ -30 | -22 |
| 高光 | -20 ～ -45 | -32 |
| 阴影 | +25 ～ +50 | +38 |
| 白色色阶 | -8 ～ -28 | -18 |
| 黑色色阶 | +8 ～ +24 | +14 |
| 纹理 / 清晰度 / 去朦胧 | -5 ～ 0 / -5 ～ +3 / -2 ～ +3 | -2 / 0 / 0 |
| 自然饱和度 / 饱和度 | 0 ～ +12 / -10 ～ -3 | +6 / -6 |

原片严重欠曝时，曝光可到 +1.8 ～ +2.4，但应配合局部蒙版与高光保护，不让人物面部和白衣变灰白。

## 曲线、HSL 与冷暖

- RGB 曲线采用浅 S：黑场输出约 8～15，暗部托起，中间调略上推，亮部柔收；若画面变雾，先略压暗部第 2 点，不要继续提黑。
- 橙色：色相 -12～-3、饱和度 -12～-3、明度 +8～+18，保持皮肤亮润。
- 黄色：色相 -25～-8、饱和度 -30～-10；绿色：色相 -70～-25、饱和度 -45～-15、明度 +5～+20。只调整画面真实存在的颜色。
- 青蓝：降低过量饱和，阴影可轻微偏 200～220 色相、4～10 饱和度；高光可轻微偏 42～55 色相、5～12 饱和度。效果应几乎看不出滤镜痕迹。
- 人物整体偏暖时，使背景相对偏冷；人物偏冷时反向处理。不得让人物边缘出现冷暖光晕。

## 婚纱与黑西装

婚纱、头纱、白衬衣：以高光和白色色阶控制，不用整体曝光硬冲；保留刺绣、纱网、珠饰和褶皱。黑西装、黑发、蝴蝶结：提阴影只打开必要纹理，保持深色锚点；检查缎面、枪驳领和布料高光不变灰、不死黑。

## 验收与回退

缩小检查整体是否亮、净、透，原尺寸检查肤色、白衣纹理和深色衣物。若亮了却发灰，降低全局曝光 0.1～0.3、减少阴影提亮，并压曲线暗部第 2 点 3～6；若白衣死白，继续降低高光和白色色阶；若肤色黄脏，先降橙黄饱和、提橙色明度，不直接加红色饱和度。

## 配饰特征强制保留

耳饰、头饰、头纱装饰、戒指、项链、手链、胸针、眼镜及服装上的识别性配件均不得替换、增删、改形、改颜色、改变材质、改变佩戴位置或遮挡关系。仅可在不改变其原貌的前提下清理污点、恢复局部清晰度和合理高光；生成式编辑后逐件复核饰品数量、形状、纹理、连接处及与头发、耳朵、手指、衣物的遮挡关系。
